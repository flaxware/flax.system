// The project

More than a theme. A system in progress.

The project explores a modern operating system concept built around privacy, usability, and explicit security choices.

FLAX SYSTEM is a security-first operating system concept focused on privacy, flexibility, and everyday computing. It combines a Unix-inspired design with a practical approach to system structure, isolation, and user control.

The goal is not only to make a technically secure system, but to make secure defaults understandable, reasonable, and usable for daily work.

// System architecture

A layered approach to security and usability.

FLAX SYSTEM explores a modular, Unix-inspired design with layered protection and clear responsibilities.

Security center

FlaxDefender

Anti-virus, cleaner, system monitoring, and security awareness.

Isolation

FlaxBox

Knox-like and Qubes OS inspired encrypted workspaces and isolation layer for containers, virtual machines, and applications.

Networking

FlaxNet

Network layer, firewall management, gateway concepts including optional TOR or VPN routing, traffic filtering and control.

Browser

Fenyx

Firefox-based browser with TOR, VPN, ad-blocking and strict privacy focused settings.

Desktop

Nitro

XFCE-based desktop environment with focus on being user friendly and security-first.

Blueprint

Unix-inspired design

Plain-text configuration, hierarchical organization, explicit permissions, privilege separation, and modular components.

// Project ideals

Designed around clear principles.

  • GeneralDesigned for every purpose with everyday computing in mind.
  • EfficientKeep the system lightweight and stable, old hardware becomes modern new.
  • PerfectFully configured out of the box, no need to mess around.
  • FlexiblePlain text is sacred, structure is natural.
  • PortableModular components like bricks building hierarchy, organize components so they can be maintained and reused.
  • SafeSecurity is built in, not optional.
