FLAXWARE · FLAX SYSTEM

A system for secure, everyday computing.

FlaxOS is a Unix-like operating system project exploring security, privacy, flexibility, and general-purpose usability. Its goal is to make thoughtful security concepts approachable without losing sight of daily computing.

// System architecture

A layered approach to security and usability.

These are project components and design directions described in the repository documentation. Their availability and maturity can vary; consult the source repository for implementation status.

Security center

FlaxDefender

Anti-virus, cleaner, system monitoring, and security awareness.

Isolation

FlaxBox

Knox-like and Qubes OS inspired encrypted workspaces and isolation layer for containers, virtual machines, and protected user data.

Networking

FlaxNet

Network layer, firewall management, gateway concepts including optional TOR or VPN routing, traffic separation, DNS encryption and leak prevention.

Browser

Fenyx

Firefox-based browser with TOR, VPN, ad-blocking and strict privacy focused settings.

Desktop

Nitro

XFCE-based desktop environment with focus on being user friendly and security-first.

Blueprint

Unix-inspired design

Plain-text configuration, hierarchical organization, explicit permissions, priveledge separation, and OpenBSD kernel behaviour.

Designed around clear principles.

  • GeneralDesigned for every purpose with everyday computing in mind.
  • EfficientKeep the system lightweight and stable, old hardware becomes modern new.
  • PerfectFully configured out of the box, no need to mess around.

  • PortableModular components like bricks building hierarchy, organize components so they can be maintained and reused.
  • SafeSecurity is built in, not optional.

// Verify before installing

Trust the artifact, not just the link.

Use verification data published for that exact build

Before installing an image, check the official download page for a checksum or cryptographic signature associated with the same version and architecture. Do not rely on values copied from an unrelated mirror or unverified post.

  1. Download the image and any checksum or signature files linked by the official download instructions.
  2. Compare the image’s SHA-256 digest with the official checksum, if one is provided (for example, using sha256sum on Linux).
  3. If a signature and signing-key fingerprint are published, verify the signature and confirm the fingerprint using an independent official project source.
  4. If matching verification data is missing or does not match, do not install that image; check the repository or contact the maintainers.

Only trust checksum/signature material published alongside the specific release. This page does not claim that a particular image or signature is currently available.
