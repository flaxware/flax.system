FLAXWARE · SYSTEM PROJECT

A system for secure, everyday computing.

FlaxOS is a Unix-like operating system project exploring security, privacy, flexibility, and general-purpose usability. Its goal is to make thoughtful security concepts approachable without losing sight of daily computing.

// The project

More than philosophy. A system in progress.

The project describes a system intended for development, creativity, productivity, and security-focused work. FLAX SYSTEM is under development; plans and proposed capabilities below should not be read as a guarantee that every feature is already implemented.

01 / General

Everyday computing

Aims to support common daily tasks while keeping security and privacy considerations visible and configurable.

02 / Privacy

Control and isolation

Explores compartmentalization, encrypted workspaces, privacy modes, and isolated network paths as part of a defense-in-depth approach.

03 / Choice

Flexible workflows

Project documentation describes modular components, multiple package tools, and compatibility options for different user needs.

// System architecture

A layered approach to security and usability.

These are project components and design directions described in the repository documentation. Their availability and maturity can vary; consult the source repository for implementation status.

Security center

FlaxDefender

Planned security controls for firewall management, system monitoring, metadata cleanup, and privacy settings.

Isolation

FlaxBox

An envisioned encrypted workspace and isolation layer for containers, virtual machines, and protected user data.

Networking

FlaxNet

Network privacy and gateway concepts including optional Tor or VPN routing, traffic separation, and DNS leak prevention.

Packages

Package ecosystem

Documentation references superpkg/xpkg and ultrapkg alongside familiar Linux package formats and repository workflows.

Desktop

Daily-use environment

The project aims for a practical desktop experience, with familiar workflows, productivity software, and accessibility to general users.

Compatibility

Unix-inspired design

Plain-text configuration, hierarchical organization, explicit permissions, composable tools, and standards-aware behavior are stated design goals.

// Project ideals

Designed around clear principles.

  • GeneralDesigned for every purpose with everyday computing in mind.
  • EfficientKeep the system lightweight and stable, old hardware becomes modern new.
  • PerfectFully configured out of the box, no need to mess around.
  • FlexiblePlain text is sacred, structure is natural.
  • PortableModular components like bricks building hierarchy, organize components so they can be maintained and reused.
  • SecureSecurity is built in, not optional.

// Verify before installing

Trust the artifact, not just the link.

Use verification data published for that exact build

Before installing an image, check the official download page for a checksum or cryptographic signature associated with the same version and architecture. Do not rely on values copied from an unrelated mirror or an unverified post.

  1. Download the image and any checksum or signature files linked by the official download instructions.
  2. Compare the image’s SHA-256 digest with the official checksum, if one is provided (for example, with sha256sum on Linux).
  3. If a signature and signing-key fingerprint are published, verify the signature and confirm the fingerprint using an independent official project source.
  4. If the matching verification data is missing or does not match, do not install that image; check the repository or contact the maintainers.

Only trust checksum/signature material published alongside the specific release. This page does not claim that a particular image or signature is currently available.
